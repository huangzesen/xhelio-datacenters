Why the corpus matters语料的意义

One codebase.
Up to ten tasks.一个代码库，
可拆出十个任务。

A task is one codebase together with everything required to score a port of it — and a single codebase yields 1–10 tasks, one per module worth accelerating. Two kinds run side by side: port a CPU solver (Fortran, C, MPI) to CUDA, HIP or SYCL, or take a code that is already GPU-native and make it faster. Both score the same way, and neither needs a human to write a test.

一个任务即一个代码库连同为其打分所需的一切——而单个代码库可拆出 1–10 个任务，每个对应一个值得加速的模块。两类任务并行：将 CPU 求解器（Fortran、C、MPI）迁移至 CUDA / HIP / SYCL，或对已是 GPU 原生的代码继续提速。二者评分方式相同，且均无需人工编写测试。

01Environment环境容器The legacy code at a pinned commit, its toolchain and practice inputs.固定 commit 的原始代码、工具链与练习输入。
02The task任务Port a module to the GPU — or speed up one that already runs there.迁移某个模块至 GPU，或为已在 GPU 上的模块提速。
03Equivalence等价性判定A separate verifier container holds the references. Correctness passes only at 100% of the criteria.独立验证容器持有参考数据；须 100% 满足全部判据方为正确。

Why this trains an agent. A GPU port reorders floating-point arithmetic, so bitwise identity is unachievable by construction; each task instead states which quantity, over what horizon, within what tolerance, and why that tolerance is scientifically justified. That makes the reward machine-checkable — correct on the first shot, and how much faster — which is exactly the signal reinforcement learning needs, at a scale hand-written tests cannot reach.

为何可用于训练智能体。 GPU 迁移会改变浮点运算顺序，逐位一致在原理上不可达；因此每个任务需写明：校验哪个量、在多长时程内、容差多少、以及该容差为何在科学上成立。奖励由此可被机器判定——是否一次通过，以及加速多少——这正是强化学习所需的信号，且规模远超人工测试所能覆盖。

Where this stands: the corpus and code identification exist today. Turning an entry into a scored task still means building and pinning its environment and writing its equivalence criteria — the hard part for scientific HPC, where MPI, Fortran toolchains and input decks vary per project. 10,000+ is what the corpus makes reachable, not a count of tasks already in the registry.当前进展： 已完成的是语料与代码识别。将一条记录变为可评分任务，仍需构建并固化环境、编写等价性判据——这正是科学高性能计算的难点：MPI、Fortran 工具链与输入文件因项目而异。10,000+ 是语料使之可达的规模，而非注册表中已有的任务数。
